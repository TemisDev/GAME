# Marea Alta

Contenido propio del prototipo. Los paquetes, ajustes de URP y recursos externos permanecen fuera de esta carpeta.

## Primer objetivo jugable

Mover a Mara en ocho direcciones dentro de `Prototype_PuntaCoral`, usando un `Rigidbody2D` y límites con `Collider2D`.

## Carpetas

- `Scenes`: escenas del prototipo.
- `Scripts`: comportamiento dividido por sistema.
- `Prefabs`: objetos reutilizables.
- `Data`: datos configurables.
- `Art`: sprites, animaciones, materiales y efectos.
- `Audio`: música y efectos de sonido.
- `UI`: recursos de interfaz.

## Controles iniciales

- Movimiento: WASD, flechas o stick izquierdo de un gamepad.

Los valores del movimiento se ajustan desde el Inspector. El script no depende todavía de los sprites definitivos.
